# Employee Performance Mapping using SQL.

This project analyzes employee performance using  SQL.

It uses employee records and project records to find top performers,
check performance by department, and join employee and project data.

## Databases
- database:projectwork12

## Tables
- emprecord1 - Employee records
- projtable1 - project records
- datascience1- datascience records team records

## files in this project
-schema.sql - Creates database and tables
-queries.sql- Basic SQL queries
-emprecord_queries.sql - Queries for emprecord table (employee records)
-projtable_queries.sql - Queries for projtable1 table (project records)
-datascience1_queries.sql - Queries for datascience1 table (datascience team records)
